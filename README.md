# Cloud Healthcare SOC

## AWS Cloud Security Monitoring & Incident Response Lab

A hands-on cloud security project simulating a healthcare organization's AWS environment.

The project focuses on how a SOC analyst can monitor cloud activity, investigate suspicious events, analyze AWS logs, and document security incidents.

## Project Objectives

- Build a simulated healthcare cloud environment using AWS
- Apply fundamental cloud security controls
- Implement logging and monitoring
- Investigate simulated security incidents
- Analyze AWS activity logs
- Build incident timelines
- Document evidence and findings
- Recommend containment and remediation actions

## AWS Services

The project will explore services including:

- Amazon EC2
- Amazon S3
- AWS IAM
- Amazon VPC
- Security Groups
- AWS CloudTrail
- Amazon CloudWatch

## Project Status

🚧 In progress

The environment and investigation scenarios are being developed as part of this hands-on lab.

## Disclaimer

This project uses a fictional healthcare organization and simulated security scenarios. No real patient information or sensitive healthcare data is used.
